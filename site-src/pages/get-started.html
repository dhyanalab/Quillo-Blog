What you need

Less than you’d think.

A computer that stays on

A Raspberry Pi 4 or 5, a small rented server, or a machine at your office. Linux is the easiest home.

Node 22.13 or newer

Quillo is a Node program. It uses Node’s own SQLite, so there’s no database server to install.

A domain name

Optional, but nicer. A free Cloudflare Tunnel connects it, with no router changes and HTTPS included.

The steps

Four steps to a live blog.

Commands are for Linux. Copy each line, paste it into the machine’s terminal, and press Enter.

  1. Get Quillo

    Download the code and install its packages.

    $ git clone https://github.com/dhyanalab/Quillo-Blog.git quillo
$ cd quillo
$ npm ci

    Prefer a file? Download the ZIP from the latest release and unpack it.

  2. Try it on your computer

    Optional, but a good way to look around first.

    $ npm run dev
Blog:  http://localhost:4100/
Admin: http://localhost:4100/admin/

    Want practice posts? npm run seed -- --dev adds some, and npm run seed -- --remove takes them away again.

  3. Install it as a service

    On the machine that will run the blog, one command sets Quillo up to start by itself and restart if it ever stops.

    $ bash deploy/install.sh https://blog.example.com
✓ Quillo is running
Setup link and setup token shown here

    Then connect your domain with a Cloudflare Tunnel: add a public hostname for your blog that points to 127.0.0.1:4100. The deployment guide shows every click.

  4. Name your blog

    Open /admin/setup on your blog’s address and paste the setup token. Give your blog a name, a description and a time zone, and create the owner account.

    Then turn on two-step sign-in, choose a look on the Design page, and write your first post.

Updating

Stop the blog, put the new code in place and run npm ci again. Quillo saves a copy of your blog before it updates anything, and keeps your data folder as it is.

Questions

Good to know.

Do I need to know how to code?

No. Everything in the admin is point and click, in plain words. Installing takes a few commands, which this page lists, or we can do it for you.

Will it run on a Raspberry Pi?

Yes. Quillo is light, and a Raspberry Pi 4 or 5 runs it well.

How do I back up my blog?

Everything lives in one data folder: your posts, pictures, readers and settings. Copy that folder, and keep the secret key file somewhere safe and separate. The deployment guide explains how.

Can I run more than one blog?

Yes. Each blog is its own install with its own folder and address, so one blog never affects another.

Can it carry only my brand?

Yes. Your name, logo, colours, fonts and layouts are your choice, and the small “Powered by Quillo” line is optional.

Something went wrong. Who can help?

Write to info@dhyanalab.in. For a security problem, please write with “Quillo security” in the subject instead of opening a public issue.
