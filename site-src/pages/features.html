Running it

Small, quiet and yours.

Quillo is one program and one folder. It runs happily on a Raspberry Pi.

  • No database server: everything is kept in one file, using Node’s own SQLite.
  • One command installs it as a service that starts by itself.
  • Your own domain through a free Cloudflare Tunnel, with no router changes.
  • Safe updates: it saves a copy of your blog before changing anything.
